# ISSUES

Podemos configurar templates para as issues seguindo o passo a passo:

1. vamos em Settings;
2. issues;
3. set up templates; (assim adicionamos templates de como o usuário pode criar issues);
4. logo de início, o github te dá três opções:
   a. Bug report;
   b. Feature request;
   c. Custom template;
5. Assim que criamos os templates, qualquer um que for abrir uma Issue no nosso repositório, vai ter um template base;
