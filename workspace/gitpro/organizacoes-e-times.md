# ORGANIZAÇÕES E TIMES

**Por exemplo** o _express_ open source tem vários maintainers e por isso é tão necessário o **Pull request**.
**npm graph** é outro exemplo de projeto open source(aberto) onde o **Pull request** se faz muito importante: <https://github.com/anvaka/npmgraph.an>

O próprio **github** tem toda uma organização com mais de _250_ pessoas.
<https://github.com/github>
É interessante que cada organização pode ter vários times. Bem como podemos olhar no próprio github/docs onde podemos ver como contribuir na documentação do github
_tip_ sempre procure como o time te aconselha a fazer **pull requests** e **issues**.
